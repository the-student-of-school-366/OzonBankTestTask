# Хранилище в памяти

`memory.New()` создаёт один `Store`. Он реализует репозитории постов и комментариев. Сервис передаёт этот экземпляр обоим usecase при `STORAGE=memory`. Сборка выполняется в `cmd/service`.

Данные принадлежат процессу и исчезают при его остановке.

Общий `RWMutex` защищает записи и индексы. Проверка поста, родителя и вставка комментария проходят под той же блокировкой, что и изменение разрешения на комментарии. Чтения идут параллельно. Индексы постов, корней и ответов упорядочены по `(created_at DESC, id DESC)`: курсор ищется двоичным поиском, вставка может сдвигать элементы индекса. Страница ограничена `first + 1` записью, пакет — 100 ключами. Порядок запросов и повторы сохраняются. У возвращаемого комментария свой указатель `ParentID`, отдельный от хранилища и от других результатов.
