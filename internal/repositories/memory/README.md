# Хранилище в памяти

`memory.New()` создаёт один `Store`, который реализует оба интерфейса репозиториев.
Передайте один экземпляр в usecase постов и комментариев:

```
store := memory.New()
posts := postusecase.New(store)
comments := commentusecase.New(store, hub)
```

Данные принадлежат процессу и исчезают при его остановке. Для настройки GraphQL
и `hub` см. [README API](../../api/README.md). Подключение хранилища в исполняемом
сервисе остаётся отдельной задачей.

Общий `RWMutex` защищает данные и индексы; проверка поста, родителя и вставка
комментария выполняются под той же блокировкой, что и изменение разрешения на
комментирование. Чтения могут выполняться параллельно. Индексы постов, корней и
ответов упорядочены по `(created_at DESC, id DESC)`: поиск курсора бинарный,
вставка может потребовать сдвига элементов индекса. Страницы ограничены `first+1`,
пакеты — 100 ключами; порядок запросов и дубликаты сохраняются. Возвращаемые
комментарии не разделяют указатель `ParentID` с хранилищем или другими результатами.
